# Personal Tech Intelligence

Phase 1 is a manual, read-only technology discovery MVP.

```powershell
$env:PYTHONPATH = "D:\personal-tech-intelligence\src"
python run.py --dry-run
```

The program uses public unauthenticated GitHub REST search, SQLite identity history, bounded scoring, and local JSON/Markdown reports. It does not clone, download, install, activate, or execute third-party assets. It does not write to `D:\money`.

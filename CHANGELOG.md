# Changelog

## v0.2.0

- Human Control Center: local desktop/browser views, capability details, meaningful review states and bounded human decisions.
- Capability model: separate sources, implementations, capabilities, adopted methods and personal evidence.
- Continuous intelligence: upstream fingerprints, freshness and delta-review infrastructure.
- Activation Execution Engine: resumable, pinned, bounded low-risk validation with rollback and human gates.
- Production reuse: supported consumers record real invocation and material-use evidence, distinguishing AVAILABLE from USED.
- Self-bootstrap loop: capability-discovered candidates use canonical admission, shared Stage B, persisted final decisions and appropriate downstream lifecycles.
- Publication safety: separate local installs, readiness, approvals and personal projections from portable product defaults; configurable Codex models and clean-install/migration checks.

Generic executable third-party tools remain blocked without a secure execution substrate. This release does not add an OS sandbox.

## v0.1.0

- Initial public technical radar, semantic review, local capability library and containment-focused adoption workflow.
- Python standard-library runtime, SQLite persistence and optional Windows scheduling.
